# Paper-to-Code Mapping

This document maps the frozen paper methodology and experiment questions to
the public release modules. Numbered development phases are intentionally not
used as public navigation.

## Methodology

| Paper component | Code | Main public interfaces |
|---|---|---|
| XES ingestion and preprocessing | `src/bul_project/preprocessing/` | `preprocess_dataset`, trace construction, cleaning and time processing |
| Activity statistics | `src/bul_project/behavior/activity.py` | `activity_statistics` |
| DFG edge statistics | `src/bul_project/behavior/dfg.py` | `dfg_statistics` |
| Variant statistics and Top-k+OTHER | `src/bul_project/behavior/variants.py` | `variant_statistics` |
| Transition-time statistics | `src/bul_project/behavior/temporal.py` | `temporal_statistics` |
| Unified behavioral statistics | `src/bul_project/behavior/statistics.py` | `build_g_raw` |
| Case-level clipping | `src/bul_project/privacy/clipping.py` | `clip_trace`, `clip_traces` |
| Sensitivity bounds | `src/bul_project/privacy/sensitivity.py` | `calculate_sensitivity` |
| Sequential epsilon allocation | `src/bul_project/privacy/budget.py` | `allocate_privacy_budget`, `split_temporal_budget`, `edge_only_epsilon` |
| Laplace release | `src/bul_project/privacy/laplace_dp.py` | `laplace_release` |
| DP-full and DP-edge-only | `src/bul_project/privacy/release.py` | `dp_full_release`, `dp_edge_only_release` |
| DP temporal reconstruction | `src/bul_project/privacy/temporal_generator.py` | `TemporalDistributionGenerator` |
| Jensen-Shannon divergence | `src/bul_project/metrics/js_metric.py` | `calculate_js` |
| Cosine similarity converted to loss | `src/bul_project/metrics/cosine_metric.py` | `calculate_cosine_similarity`, `calculate_cosine_loss` |
| EMD and normalized EMD | `src/bul_project/metrics/emd_metric.py` | `calculate_emd`, `calculate_normalized_emd` |
| Entropy deviation | `src/bul_project/metrics/entropy_metric.py` | `calculate_entropy_loss` |
| Structure loss | `src/bul_project/bul/structure_loss.py` | `calculate_structure_loss` |
| Temporal loss | `src/bul_project/bul/temporal_loss.py` | `calculate_temporal_loss` |
| Information loss | `src/bul_project/bul/information_loss.py` | `calculate_information_loss` |
| BUL aggregation | `src/bul_project/bul/bul_score.py` | `calculate_BUL`, `calculate_fixed_entropy_weights` |

## Experiments and research questions

| Paper experiment role | Code | Public command |
|---|---|---|
| Parameter diagnostics and freeze | `src/bul_project/experiments/parameter_freeze.py` | `python main.py freeze-parameters` |
| One experiment condition | `src/bul_project/experiments/single_run.py` | internal reusable API |
| Dataset/epsilon/method/seed batching | `src/bul_project/experiments/batch_run.py` | used by the main runner |
| 3150-condition main experiment | `src/bul_project/experiments/main_experiment.py` | `python main.py run-main` |
| Equal-weight and entropy-weight BUL derivation | `src/bul_project/experiments/bul_analysis.py` | `python main.py derive-bul` |
| Dimension ablation | `src/bul_project/experiments/bul_analysis.py` | generated by `derive-bul` |
| Cross-dataset descriptive comparison | `src/bul_project/experiments/bul_analysis.py` | generated by `derive-bul` |
| Top-k and edge-threshold sensitivity | `src/bul_project/experiments/sensitivity.py` | `python main.py run-sensitivity` |
| Wilcoxon, Friedman, Holm, bootstrap and Spearman | `src/bul_project/statistics/` | `python main.py analyze` |
| Representative PM4Py feasibility validation | `src/bul_project/validation/` | `python main.py run-external-validation` |
| Quick reviewer demonstration | `scripts/run_demo.py` | `python main.py demo` |
| Complete local reproduction | `scripts/reproduce_paper.py` | `python main.py reproduce-paper` |

## Provenance

| Traceability item | Implementation |
|---|---|
| Complete code manifest | `src/bul_project/provenance.py::build_code_manifest` |
| Local artifact manifest | `src/bul_project/provenance.py::build_release_manifest` |
| Manifest generation/verification | `python main.py build-manifest [--verify]` |
| Clean release inventory | `release_inventory.json` |
| Historical development mapping | `docs/history/phase_mapping.md` |

PM4Py Fitness, Precision, and Generalization are representative external
feasibility outputs only. They are not components of BUL and are not used to
claim correlation-based validation of BUL.
